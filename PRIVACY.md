# SuperChrome Privacy Policy

SuperChrome does not collect, store, or transmit any user data.

- All functionality runs locally in your browser.
- Settings are stored via Chrome's `storage.sync` (synced by Chrome itself, tied to your Google account, never visible to us).
- Usage counts that rank your most-used items are stored in `storage.local` on your device only.
- No analytics, no telemetry, no external servers, no accounts.
- The optional native helper (installed manually from this repository) runs only on your machine and communicates only with this extension.

The extension's source code is public in this repository, so every claim above is verifiable.

Questions: open an issue on this repository.
